Internship Tasks

Your 30-day journey, one task at a time

TechBridge runs a structured 30-day practical internship. You build your web development skills step by step by completing 8 real projects, and each task builds on the one before it.

  • 8 tasksfrom Day 1 to Day 26
  • Step by stepfrom beginner to advanced

The 8 tasks

Follow the path from top to bottom. The tasks get more challenging as you go, and you can open any task to see what you will build.

  1. Day1
    Task 1 Open Day 1

    Build the TechBridge Homepage

    Create the first version of the TechBridge website using HTML and CSS.

    Beginner
    What you will build

    You build the first version of the TechBridge homepage: a clear page with navigation, sections and a call to action.

    • HTML
    • CSS
    • Page layout
  2. Day4
    Task 2 Open Day 4

    Build the TechBridge Programs Experience

    Create a Programs experience that presents TechBridge's available learning programs.

    Beginner → Intermediate
    What you will build

    You build on your homepage with a Programs page that explains the learning programs and links back to the rest of the site.

    • HTML
    • CSS
    • Responsive design
  3. Day8
    Task 3 Open Day 8

    Build the Internship Tasks Experience

    Create an interface that presents the TechBridge internship tasks and helps users understand the internship journey.

    Beginner → Intermediate
    What you will build

    You design a page that shows all eight tasks, when each one happens and how the internship progresses.

    • HTML
    • CSS
    • Information design
  4. Day11
    Task 4 Coming up Day 11

    Build an Interactive Task Tracker

    Use JavaScript to make the internship task experience interactive and allow progress to be tracked.

    Intermediate
    What you will build

    You add JavaScript to the tasks experience so interns can interact with it and track their progress.

    • JavaScript
    • DOM
    • Progress tracking
  5. Day15
    Task 5 Coming up Day 15

    Build the Intern Registration Experience

    Create a professional registration/onboarding interface for TechBridge interns.

    Intermediate
    What you will build

    You create a professional registration and onboarding interface for new TechBridge interns.

    • Forms
    • Validation
    • UX
  6. Day19
    Task 6 Coming up Day 19

    Build the Task Submission System

    Create an interface through which interns can prepare and submit their task work.

    Intermediate
    What you will build

    You build an interface where interns can prepare their task work and submit it.

    • Forms
    • JavaScript
    • UX
  7. Day22
    Task 7 Coming up Day 22

    Build the Intern Dashboard

    Create a dashboard where an intern can view their profile, progress, tasks, and submissions.

    Intermediate → Advanced Beginner
    What you will build

    You create a dashboard where an intern can see their profile, progress, tasks and submissions in one place.

    • Dashboard layout
    • JavaScript
    • Data display
  8. Day26
    Task 8 Coming up Day 26

    Build the Complete TechBridge Internship Platform

    Combine the different components created during the internship into a complete TechBridge platform.

    Intermediate → Advanced Beginner
    What you will build

    You bring the components from earlier tasks together into one complete TechBridge platform.

    • Integration
    • Project structure
    • Polish
