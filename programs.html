Program 01

Data Analytics

Working with data and extracting insights

This program introduces you to practical data analysis. You learn to prepare data, ask questions of it, and present what you find in a way that helps people make decisions.

Find patterns. Answer questions. Show what you discover.

Skills you will build

  • Spreadsheet analysis Organise, sort and summarise data to see what it says.
  • Data cleaning Fix errors and gaps so the data can be trusted.
  • SQL Ask databases for exactly the data you need.
  • Data visualization Turn numbers into charts people can read quickly.
  • Business-focused analysis Answer real business questions with clear findings.

A good fit if you like finding the story inside numbers and explaining it clearly.

Program 02

Web Development

Designing and building websites and web applications

This program introduces you to practical website development. You learn the tools developers use every day and use them to plan, build and ship real web pages.

<h1>Hello, world</h1><p>Built by me.</p>

Plan it. Build it. Put it online.

Skills you will build

  • HTML Structure the content of a web page.
  • CSS Style pages and make layouts work on any screen.
  • JavaScript Add behaviour and interactivity to your pages.
  • Git/GitHub Track your changes and share your code.
  • Building web projects Take a page from idea to something live.

A good fit if you like making things you can see and click, and want to learn how websites are put together.
